## How to Use This Roadmap

* **Don't rush.** Each phase has a reason for its position.
* **Code along.** Watching is not learning. Type every example yourself.
* **Revisit.** After Phase 3, go back to Phase 1 and 2 examples.
* **Build the projects.** They tie the concepts together.
* **Ask questions.** If something doesn't click, find the missing piece.

> **Learn → Understand → Practice → Connect → Build**
